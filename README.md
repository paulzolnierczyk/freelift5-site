# freelift5-site

The public pages for the FreeLift5 app, served by GitHub Pages:

- https://paulzolnierczyk.github.io/freelift5-site/ — about the app
- https://paulzolnierczyk.github.io/freelift5-site/privacy/ — privacy policy
- https://paulzolnierczyk.github.io/freelift5-site/support/ — support
- https://paulzolnierczyk.github.io/freelift5-site/terms/ — terms of use

The app's source is private; these pages are copied from its `docs/store` folder, where they are
reviewed with the app.

Questions or problems with the app: open an issue here. Please don't attach backup files or
exports of your training history; issues are public.
